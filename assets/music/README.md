# Background Music for Reels

Drop any royalty-free `.mp3`, `.wav`, or `.m4a` tracks into this folder.
When the Reel workflow runs, it picks one track at random, trims it to 6 seconds with a smooth fade-in and fade-out, and mixes it into the MP4 Reel.

If this folder has no audio files, the Reel will be generated with a silent audio track.
